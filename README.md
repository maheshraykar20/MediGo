### 2. 🏪 मेडिकल स्टोअर प्रोफाईल आणि लोगो/फोटो अपलोड (Store Profile & Logo Upload)
- हेडर किंवा साइडबारमधील **"प्रोफाईल (Profile)"** पर्यायावर क्लिक करून:
  - **लोगो किंवा दुकानाचा फोटो अपलोड**: तुमच्या मेडिकल स्टोअरचा लोगो किंवा फोटो (PNG/JPG/WebP, कमाल २ MB) अपलोड करू शकता. हा लोगो थेट हेडर, साइडबार आणि अहवालांवर दिसतो.
  - **स्टोअरचे नाव**: तुमच्या दुकानाचे नाव (उदा. *Sanjivani Medical & General Store*).
  - **फार्मसिस्ट / मालकाचे नाव व पदवी**: (उदा. *Mahesh Patil, B.Pharm*).
  - **ड्रग्ज लायसन्स क्रमांक (20B व 21B)**.
  - **जीएसटी क्रमांक (GSTIN)**.
  - **फोन व WhatsApp क्रमांक**: जो थेट सप्लायरला पाठवल्या जाणाऱ्या रिटर्न मेसेजमध्ये वापरला जातो.
  - **दुकानाचा पत्ता व शहर**.
  - सर्व प्रोफाईल माहिती ब्राऊझरच्या LocalStorage मध्ये कायमस्वरूपी सेव्ह राहते.

## 🚀 सुरू कसे करायचे? (How to Run)

प्रकल्प `Daivtam/Medical` फोल्डरमध्ये उपलब्ध आहे:

```bash
# 1. Medical फोल्डरमध्ये जा
cd Medical

# 2. डेव्हलपमेंट सर्व्हर सुरू करा
npm run dev

# 3. प्रोडक्शन बिल्ड तयार करा
npm run build
```

- **लोकल डॅशबोर्ड**: [http://localhost:5175/](http://localhost:5175/)
- **मोबाईलवर पाहण्यासाठी (वायफाय नेटवर्क)**: `http://192.168.31.220:5175/` (किंवा तुमच्या संगणकाचा स्थानिक आयपी)
